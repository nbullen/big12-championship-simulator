# Big 12 Championship Simulator

Unofficial fan-built football what-if simulator.

Open the GitHub Pages website to use it on a phone or desktop. Pick a team, lock remaining game results, and simulate the conference.

Embedded November 9, 2026 snapshot, not a live feed. Independent 50/50 simulated games are not predictive odds. Official policy sources and limitations are included inside the app. Picks remain in browser storage; no picks are uploaded.
